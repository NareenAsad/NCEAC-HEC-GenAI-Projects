# NCEAC-HEC GenAI Projects

This repository contains hands-on projects developed during the **NCEAC-HEC Generative AI Training (Cohort 1)**. These projects cover practical applications of Generative AI in solving real-world problems and enhancing productivity.

## Repository Structure

```
NCEAC-HEC-GenAI-Projects/
│
├── Module-2/           # Projects from Module 2
├── Module-3/           # Projects from Module 3
├── Module-4/           # Projects from Module 4
├── README.md           # Project documentation
└── requirements.txt    # Required Python libraries
```

## Modules Overview

* **Module 2**: Introduction to Generative AI, prompt engineering, and foundational projects.
* **Module 3**: Advanced AI techniques including embeddings, semantic search, and AI-assisted coding.
* **Module 4**: Real-world AI applications such as RAG (Retrieval-Augmented Generation), AI chatbots, and deployment strategies.

## Features

* **Hands-on Jupyter Notebooks** with step-by-step explanations.
* **Python scripts** for AI workflows and automation.
* **Focus on Generative AI** tools and techniques for practical use cases.

## Getting Started

### Prerequisites

* Python 3.10+
* Pip package manager

### Installation

1. Clone the repository:

```bash
git clone https://github.com/NareenAsad/NCEAC-HEC-GenAI-Projects.git
cd NCEAC-HEC-GenAI-Projects
```

2. Install required libraries:

```bash
pip install -r requirements.txt
```

3. Open the notebooks in Jupyter:

```bash
jupyter notebook
```
