# 🐾 Animal Classifier App

A deep learning-based image classification application capable of identifying 90 different animal species. The model is built using TensorFlow/Keras with Transfer Learning (EfficientNetB0) and deployed via a user-friendly Gradio interface.

## 🚀 Features
- **90 Animal Classes**: Can distinguish between a wide variety of animals including mammals, birds, reptiles, and insects.
- **High Accuracy**: Achieved ~96% accuracy on the validation set using Transfer Learning.
- **Interactive UI**: Simple web interface powered by Gradio for easy image uploading and prediction.

## 📂 Project Structure
- `app.py`: The main entry point for the Gradio application.
- `image_classification_pipeline.ipynb`: Jupyter notebook containing the complete data pipeline, model training, and evaluation steps.
- `requirements.txt`: List of Python dependencies required to run the project.
- `class_indices.json`: JSON file mapping model output indices to animal names.
- `animal_classifier_model.h5`: The trained model file (ensure this is present before running).

## 🧠 Model Details
- **Architecture**: EfficientNetB0 (pre-trained on ImageNet).
- **Training**:
  - Initial training with frozen base layers.
  - Fine-tuning of the top 50% of layers.
- **Performance**: ~96% Validation Accuracy.

## 🛠️ Installation

1. **Clone the repository** (if applicable) or navigate to the project directory.

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## ▶️ Usage

1. Ensure you have the trained model file `animal_classifier_model.h5` and `class_indices.json` in the project directory. (These are generated by running the `image_classification_pipeline.ipynb` notebook).

2. Run the application:
   ```bash
   python app.py
   ```

3. Open the provided local URL (usually `http://127.0.0.1:7860`) in your browser.

4. Upload an image of an animal and click **Submit** to see the prediction!

## 📊 Dataset
The model was trained on the **Animal Image Dataset (90 Different Animals)**, which contains 5400 images belonging to 90 classes.
