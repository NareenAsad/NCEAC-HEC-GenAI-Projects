# 🧠 Module 3 – Main Training Sessions on Developing Generative AI Applications

This module focuses on applying core Generative AI concepts to real-world use cases, including chatbot development, NLP data cleaning, embedding-based RAG workflows, and practical API integration.
It covers hands-on development of functional AI systems that use preprocessing, vectorization, embeddings, and interaction with large language models.

---

## 📚 Module Overview

**Module Title:** Main Training Sessions on Developing Generative AI Applications
**Duration:** **2nd – 6th November 2025**

---

## 🧩 Learning Outcomes

By completing this module, you will learn to:

* Understand how APIs work and how to integrate them into chatbot workflows.
* Build functional chatbots using Python, Groq API, and Gradio UI.
* Apply complete NLP text preprocessing pipelines for real-world datasets.
* Perform advanced data cleaning and feature preprocessing for ML/NLP workflows.
* Implement RAG (Retrieval-Augmented Generation) pipelines with **fine-tuned embeddings**.
* Work with vector stores and embedding-based retrieval.
* Organize professional-level AI projects for deployment and version control.

---

## ⚙️ Development Workflow

1. 🔍 **Study** API fundamentals, LLM interactions, and preprocessing pipelines
2. 🤖 **Develop** chatbot and NLP applications using Python & Groq
3. 🧪 **Test** apps inside Google Colab and local runtime
4. 🧱 **Build** RAG pipelines with embedding models
5. 📦 **Package** your work with documentation and GitHub-friendly structure

## 💻 Projects Completed in This Module

### 🤖 API & Chatbot Understanding

**Description:**
A project focused on understanding API architecture, calling Groq LLM endpoints, and building a chatbot with a clean Gradio UI.

**Tech Stack:**

* Python
* Groq API
* Gradio
* LLaMA-based models

---

### 🛎️ Customer-Support FAQ Chatbot

**Description:**
A domain-specific FAQ chatbot using NLP preprocessing to normalize text, clean user queries, and generate consistent responses.

**Tech Stack:**

* Python
* NLP preprocessing
* Groq LLM
* Gradio

---

### 🧼 Data Cleaning & Preprocessing

**Description:**
A full data preprocessing workflow including: missing-value handling, encoding, feature engineering, and scaling.
This project prepares datasets for ML training and downstream modeling.

**Tech Stack:**

* pandas
* numpy
* scikit-learn

---

### 🔤 NLP Data Cleaning

**Description:**
Implementation of a complete NLP preprocessing pipeline, including:

* lowercasing
* tokenization
* stopword removal
* punctuation cleaning
* lemmatization

**Tech Stack:**

* Python
* NLTK / spaCy
* Regular expressions (regex)

---

### 📚 RAG Pipeline with Fine-Tuned Embeddings

**Description:**
A Retrieval-Augmented Generation pipeline that uses **custom fine-tuned embeddings** for improved document similarity.
Includes document preprocessing, embedding generation, vectorstore storage, retrieval, and final LLM response generation.

**Tech Stack:**

* Python
* Groq / embedding models
* FAISS or vector databases
* RAG architecture
* Prompt engineering
